# Beyond Relics — 30-second judge demo

Use this as a recording script only after the deployed site and the Apollo GeoCSV import have been tested on the recording device. Speak clearly; keep the browser interaction visible.

## 30-second narration

**0–5 sec — The question**  
“When a space mission falls silent, what remains—and what can it still teach us?”

**5–11 sec — The artifact**  
“Beyond Relics follows the hardware NASA left on the Moon and Mars. This is Apollo 12’s passive seismic experiment: a scientific instrument deployed on the lunar surface.”

**11–21 sec — The evidence**  
“Its observations were preserved in NASA’s Planetary Data System. Here, we load an original Apollo 12 GeoCSV file and plot the values with transparent descriptive statistics.”

**21–26 sec — The learning experience**  
“Then young explorers test what they discovered in a source-linked mission investigation.”

**26–30 sec — The legacy**  
“The hardware remains. The evidence teaches. The next generation investigates.”

## Screen sequence

1. Open the Apollo 12 artifact record. Keep the artifact name and mission visible.
2. Open **NASA Data Lab → Apollo waveform lab**.
3. Load the NASA PDS sample. If remote loading fails, use the original NASA CSV download and the local-file import. Do not switch to fabricated or illustrative values.
4. Point to the chart and at least one statistic. State that these are descriptive statistics, not an event classification.
5. Open the Mission Investigator quiz and answer one question, showing its NASA evidence link.
6. End on the project home page and state the learning outcome.

## If the data import fails during recording

Do not fake a successful live load. Either:
- demonstrate the local-file import using the original downloaded NASA PDS file; or
- use the 7-slide alternative below and clearly label any screenshot as a previously captured result only after it has been verified.

## Seven-slide alternative

1. **Title:** Beyond Relics — Real missions. Lasting legacies.
2. **Challenge:** What remains when machines fall silent on the Moon and Mars?
3. **Artifact:** Apollo 12 passive seismic station — purpose and physical legacy.
4. **NASA evidence:** Apollo PSE dataset citation, exact file name, archive source, and fields actually used.
5. **Investigation:** verified waveform plot and descriptive statistics; include a plain-language method note.
6. **Learning impact:** show the source-linked Mission Investigator activity and how it checks understanding of the mission evidence.
7. **Sources & disclosures:** NASA references, tools/assets, AI-use disclosure, and public project URL.

## Accuracy and eligibility gates

- Verify that Apollo PSE appears in the exact **Challenge 01 Resources** list before claiming it satisfies the Global Award data requirement.
- If the listed qualifying dataset is different, integrate that exact resource and update the demo.
- Never call the waveform a moonquake, impact, or other event unless a scientifically supported method and validation justify that classification.
- Do not claim the browser parser or remote fetch is tested until the team has tested the actual source file on the deployed site.
- Keep the final submitted video at or below 30 seconds, or the slide deck at or below 7 slides including title and closing slides.
